# Experiment 6: Secure Remote Login Using SSH

This experiment demonstrates secure remote login using SSH with password-based and public-key authentication.

## Contents

- `Codes/` — Client-side and server-side commands used during the experiment.
- `Outputs/` — Screenshots documenting the experiment.

## Objective

To establish secure remote access between a Kali Linux client and an Ubuntu server using SSH, and to examine password authentication, public-key authentication, and SSH host-key verification.

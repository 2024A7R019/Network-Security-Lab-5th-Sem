# Experiment 7: Analyze WPA2 Wireless Security and Capture Handshake with Wireshark

This experiment demonstrates the capture and analysis of the WPA2 four-way handshake using Wireshark.

## Contents

- `Codes/` — Commands and supporting files used during the experiment.
- `Outputs/` — Screenshots documenting the experiment.

## Objective

To capture and analyze the WPA2 four-way handshake using Wireshark to understand secure wireless communication.
